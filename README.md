# My First Flask Application

A simple web application created using Python and Flask.

## Technologies Used
- Python
- Flask
- VS Code

## Installation

Install Flask using the following command:

```bash
pip install flask
```

## How to Run

Run the application:

```bash
python app.py
```

Open your browser and visit:

http://127.0.0.1:5000

## Output
